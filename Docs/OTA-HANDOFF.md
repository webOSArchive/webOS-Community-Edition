# OTA hand-off: CE 3.1.0 → 3.2.0 (Path A)

State at the end of 2026-11-20, everything pushed. The plan and every finding are in
[OTA-PLAN.md](OTA-PLAN.md): §2.0 (the measurement) and §2.0a to §2.0k (every run on a
device, in order), §2.2 (`ce-ota-finish`). This page is where it stands and what to do
next. It replaces the hand-off written at `cbdb396`.

## In one paragraph

An unsigned payload that turns a 3.1.0 rootfs (600070) into 3.2.0 is generated by a tool,
and it **has gone through the stock update ramdisk** (`make-update-uimage`, `PmUpdater`,
`mmipkg`) on both test TouchPads, clean and lived-in, armed by hand. A job baked into the
image (`ce-ota-finish`) finishes the update on the first boot. **Not done:** signing, the
OTA client driving any of it, a failure inside the ramdisk, AT&T. **600114 is the latest
image; three fixes to the finish job are in the tree after it and need a bake before the
next run.**

## Unbaked, waiting for the next bake (600115)

All three were found on the 600114 run and re-run on that device by hand (§2.0k):

1. `ce-ota-finish` records the staged file's version before each install: ipkg refuses to
   install over a higher recorded version, and said SUCCESS anyway.
2. `ce-preload-versions` does nothing while an update is unfinished; the finish job calls it.
3. The feed-leftover step removes Media TLS's scripts (an `ls` of four files had skipped
   every package).

Also in the tree: `device-check.py --delta` (a tool, not in the image).

**A bake needs the user's word.** A bake must contain everything finished.

## The armed flash, by hand

1. The device must be at 600070, **first use finished** (`/var/luna/preferences/ran-first-use`)
   and no `ce-*` job running (`initctl list | grep ") ce-"`; `woce-backupd` always runs).
2. Save a file list of `/media/internal` and run the pre-flight (`--delta`). Go on only on
   "may be applied".
3. `novacom put` the ipk to `/media/internal/ce-ota/`, check its md5.
4. Session files in `/var/lib/software/SessionFiles/`: `update_list.txt` (the device path),
   `install_list.txt` (the same under `/rootfs`), and `urls`: **a header line, a line that
   is exactly `version=1`, then five lines for each package.** It is not a list of URLs.
5. `/usr/bin/PmUpdater -v` (validates without installing). `update_status.txt` must stay
   empty.
6. `echo 1 > /var/lib/software/updating`, then
   `/usr/share/ota-scripts/make-update-uimage </dev/null >/tmp/mu.out 2>&1`,
   check `/boot/uImage -> update-uimage`, `killall fbprogress`, reboot.
7. About 100 seconds in the ramdisk, then the new image. `ce-ota-finish` needs one to two
   minutes after boot. Read `/var/log/ce-ota-finish.log`, `/var/luna/preferences/ce-ota-finish*`,
   `/var/log/ota.log.gz`, `/var/log/reports/librdx/`.
8. `device-check.py` against the new JAR; compare the file list of `/media/internal`
   (differences under `.palm` are cryptofs's own storage).

A refused update backs out by itself: flag removed, `uImage` link restored, reboot to the
old OS. If the device sticks in the ramdisk: `../webos-update-exploration/OTA-UPDATE-GUIDE.md`,
"Device Stuck in OTA Ramdisk".

novacom: pass scripts on stdin (`novacom run file://bin/sh <<EOF`); the device has no
`stat` or `sha256sum`; `ipkg compare_versions` exits 1 for true.

## Decisions made on 2026-11-20 that the user can still reverse

- **HP's eleven data migrations do not run on an update** (600113 onward; `bake.py` ships
  `migration.json` without them). On a Doctor-flashed device none has ever run, and three of
  them rewrite every contact and person. §2.0h.
- **Auto-correct ranking**: the hand-off's patch plus a guard on the automatic-correction
  margin, chosen for fewer wrong corrections over one more fix in a hundred.
  `AUTOCORRECT-RANKING-HANDOFF.md` §4.
- **The pre-flight refuses only a device that is another build** (or unreadable). Drift is
  either replaced by the update or kept as the owner's, and reported. §2.0k.

## Things that will bite

- **Never rebuild a JAR for a mark that was shared.** 600105 went to other developers.
  600108 to 600114 have not left this machine.
- **`ce-ota-finish` knows no version.** It compares the image it runs in with the origin
  lists. A new origin image means a new list (`make-payload.py finish-list`), nothing else.
- **A flashed device does nothing in that job**: no `ran-first-use` at boot means it writes
  both flags and exits. Keep that property.
- **Installs go through `com.palm.appinstaller/installNoVerify`**, never plain
  `app-install`/`ipkg`: only LunaSysMgr's installer registers a package's services on the
  bus. It deletes the ipk it is given a second or more after it says SUCCESS.
- **A flashed device is not the rootfs tar.** The Doctor adds `hp.tar`'s four customization
  ipks. `hp.tar` is identical in 600070 and 600114; check that again for any new pair.
- **The NVRAM write is real.** `trenchcoat` rewrites the whole 4 MB partition, tokens
  included. The job saves it to `/var/ce-ota-nvram-backup.img` first.
- **A device test that reads files is not a test that the thing works.** Calculator was on
  every 3.2.0 image and could not open; `ce-test-full.sh` only looked at its `appinfo.json`.
- **The OTA client, server and keys live in `../webos-update-exploration`.** Its
  `OTA-3.1.0.md` is the reference. `Docs/OTA-STRATEGY.md` here is stale.
